## English

A pixel-style skill experience tracker that helps you record and manage your personal skill learning progress.

### 🎮 Features

- **📊 Dashboard**: Real-time display of total EXP, today's EXP, skill count, and highest level
- **🎯 Skill Management**: Create, edit, and delete skills with multiple categories (Learning, Sports, Creative, Life, Other)
- **⚡ Experience Recording**: Quick EXP addition with shortcut buttons and notes
- **📚 History Records**: View all experience gain records
- **🎨 Theme Switching**: Support multiple color themes (Default Green, Blue, Purple, Orange, Red)
- **💾 Local Storage**: All data saved in browser local storage

### 🚀 Quick Start

1. Open the `index.html` file directly in your browser
2. Create your first skill in the "Skills" page
3. Add experience points for skills in the "Add Record" page
4. View your progress statistics in the "Dashboard"

### 📈 Level System

- Level calculation formula: `level = floor(sqrt(exp / 100)) + 1`
- Different level ranges have different color displays
- Progress bars show current level experience progress

### 🎨 Pixel Style Design

- Uses Press Start 2P pixel font
- Classic pixel game color scheme
- Square borders and shadow effects
- Retro game interface style

### 📁 File Structure

```
├── index.html      # Main page file
├── styles.css      # Style file (pixel style)
├── script.js       # JavaScript logic
└── README.md       # Project documentation
```

### 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: LocalStorage
- **Font**: Google Fonts (Press Start 2P)
- **Design**: Pixel Style UI

### 💡 Usage Tips

1. **Skill Categories**: Use categorization wisely to manage different types of skills
2. **Experience Recording**: Record learning achievements promptly to maintain continuity
3. **Notes Feature**: Write down specific learning content when adding experience
4. **Theme Switching**: Choose your favorite color theme to enhance user experience

### 📱 Responsive Design

Supports desktop and mobile access with adaptive screen sizes.

## 中文

一个像素风格的技能经验追踪器，帮助你记录和管理个人技能的学习进度。

### 🎮 功能特色

- **📊 数据面板**: 实时显示总经验值、今日经验、技能数量和最高等级
- **🎯 技能管理**: 创建、编辑和删除技能，支持多种分类（学习、运动、创意、生活、其他）
- **⚡ 经验记录**: 快速添加经验值，支持快捷按钮和备注
- **📚 历史记录**: 查看所有经验获取记录
- **🎨 主题切换**: 支持多种颜色主题（默认绿色、蓝色、紫色、橙色、红色）
- **💾 本地存储**: 所有数据保存在浏览器本地存储中

### 🚀 快速开始

1. 直接在浏览器中打开 `index.html` 文件
2. 在「Skills」页面创建你的第一个技能
3. 在「Add Record」页面为技能添加经验值
4. 在「Dashboard」查看你的进度统计

### 📈 等级系统

- 等级计算公式：`level = floor(sqrt(exp / 100)) + 1`
- 不同等级范围有不同的颜色显示
- 进度条显示当前等级的经验进度

### 🎨 像素风格设计

- 使用 Press Start 2P 像素字体
- 经典的像素游戏配色方案
- 方形边框和阴影效果
- 复古游戏界面风格

### 📁 文件结构

```
├── index.html      # 主页面文件
├── styles.css      # 样式文件（像素风格）
├── script.js       # JavaScript 逻辑
└── README.md       # 项目说明
```

### 🛠️ 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **存储**: LocalStorage
- **字体**: Google Fonts (Press Start 2P)
- **设计**: 像素风格 UI

### 💡 使用建议

1. **技能分类**: 合理使用分类功能，便于管理不同类型的技能
2. **经验记录**: 及时记录学习成果，保持连续性
3. **备注功能**: 在添加经验时写下具体的学习内容
4. **主题切换**: 选择喜欢的颜色主题，提升使用体验

### 📱 响应式设计

支持桌面端和移动端访问，自适应不同屏幕尺寸。
